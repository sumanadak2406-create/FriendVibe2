# FriendVibe — ফ্রি Friend Quiz ওয়েবসাইট

## GitHub Pages-এ ফ্রি প্রকাশ
1. GitHub-এ নতুন Public repository তৈরি করো, নাম দিতে পারো `friendvibe`।
2. এই ZIP-এর ভিতরের `index.html`, `style.css`, `app.js`, এবং `README.md` ফাইলগুলো repository-র একদম root-এ upload করো (কোনো অতিরিক্ত folder-এর ভিতরে নয়)।
3. Repository → Settings → Pages খোলো।
4. Build and deployment-এ `Deploy from a branch` বেছে নাও; Branch `main`, folder `/(root)` নির্বাচন করে Save করো।
5. প্রকাশিত HTTPS URL খুলে quiz তৈরি, link share, এবং অন্য browser/device থেকে উত্তর জমা দিয়ে পরীক্ষা করো।
